Key Config / Gotchas Hit Along the Way

Probe path
GET / (not /expenses)
Reliably returns 200; /expenses without a month param returns 400, causing CrashLoop
IRSA
eks.amazonaws.com/role-arn
SA annotation; local envsubst without the variable set renders it empty, losing DynamoDB access
LBC keepTLSSecret
--set keepTLSSecret=true
Avoids rotating the webhook CA on every helm upgrade, preventing x509 unknown authority errors
Target type
ip (not instance)
ALB routes directly to Pod IPs; Pod Ready → EndpointSlice → TG target registration
ALB SG tag
ingress.k8s.aws/cluster
LBC uses this tag to identify and manage the ALB SG; missing it causes IAM 403s
VpcId (Helm)
--set vpcId=<vpc-id>
VPC can't be auto-discovered when IMDS hop limit=1; CI fetches it dynamically via aws eks describe-cluster
