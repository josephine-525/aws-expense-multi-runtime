关键配置 / 今天的踩坑点

Probe path
GET / (not /expenses)
稳定返回 200；/expenses 缺 month 参数返回 400 导致 CrashLoop
IRSA
eks.amazonaws.com/role-arn
SA annotation；本地 envsubst 未带变量会渲染为空，导致 DynamoDB 无权限
LBC keepTLSSecret
--set keepTLSSecret=true
避免每次 helm upgrade 轮换 webhook CA，防止 x509 unknown authority
Target type
ip（not instance）
ALB 直接路由到 Pod IP；Pod Ready → EndpointSlice → TG target 注册
ALB SG tag
ingress.k8s.aws/cluster
LBC 通过此 tag 识别和管理 ALB SG；缺失会导致 IAM 403
VpcId (Helm)
--set vpcId=<vpc-id>
IMDS hop limit=1 时无法自动发现 VPC；CI 用 aws eks describe-cluster 动态取值
